# VOD-First Creator Planner

Phase 6G adapts Creator Intelligence to the creator's actual workflow:

Stream → VOD → Deliverables → Editor → Review → Publishing

Dedicated recordings remain supported, but they are not treated as the
default source.

## Content sources

Supported source types:

- Stream VOD
- Highlight candidate
- Dedicated recording
- Imported video
- Highlight compilation

## VOD deliverables

A single stream VOD can generate:

- one edited long-form episode
- multiple YouTube Shorts
- one or more TikToks
- highlight reels
- standalone clips

Each deliverable remains linked to the original VOD. This makes it possible
to measure how much content and performance each stream produced.

## Production conversion

A deliverable can be converted into a Production Management project.
The source VOD or recording is automatically added as a production asset.

## Dedicated recordings

Dedicated recordings use the same downstream production and publishing
pipeline. Only the source type changes.

## Daily planner

The planner prioritizes:

- drafts waiting for creator review
- assets blocking editor work
- ready videos without publishing slots
- today's scheduled releases
- unprocessed VODs
- editor backlog
- high-yield content sources

## Source yield

The source-yield report tracks:

- deliverables created
- production projects created
- publishing items created
- views
- watch hours
- subscribers gained
- revenue

This allows the creator to answer:

- Which streams generate the most usable content?
- Which games create the most output?
- Which VODs generate the most views?
- Is another long-form edit worthwhile?
