# Editor Workspace

Phase 7.0E.1 gives the editor a focused production queue rather than access to
the entire Creator Intelligence application.

## Queue

Projects are synchronized from Production Management when they are:

- Assets ready
- Sent to editor
- Editing
- Ready for review
- Revision requested

The queue shows assignment, priority, expected delivery, progress, revisions,
estimated hours, brief status, and editor acknowledgement.

## AI editor brief

A brief can include:

- editing objective
- project summary
- target duration
- pacing
- hook recommendation
- ending recommendation
- sections to avoid
- required editing elements
- ranked highlight moments
- scene candidates
- source assets

Briefs are versioned so regenerated guidance does not overwrite prior briefs.

## Project lifecycle

The workspace supports:

- editor acknowledgement
- editing start
- ready-for-review delivery
- creator notification
- production-status synchronization

## Notes and checklist

Each workspace project includes:

- general notes
- timestamped notes
- creator/editor authorship
- priority
- resolution status
- a standard editing checklist

## Current scope

This phase is a local desktop workspace. It does not yet provide a remote web
portal or Google Drive synchronization. Those are later integration phases.
