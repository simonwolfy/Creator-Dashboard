# Review & Revision System

Phase 7.0E.2 adds a structured review cycle after the editor workspace.

## Version control
Every submitted render is preserved as a numbered version with file location, parent version, duration, size, resolution, frame rate, export preset, change summary, submission date, and approval status.

## Timestamp comments
Comments support timestamps, frame numbers, categories, priorities, authors, assignments, threaded replies, resolution notes, and status history.

## Revision requests
Open comments can be converted into a structured revision request. Each requested change is independently tracked as Open, Complete, Skipped, or Needs discussion.

## Approval gates
A version cannot be approved until required checks are complete and all open comments are resolved. Approval synchronizes the project back to Production Management.

## Thumbnail versions
Thumbnail candidates are versioned independently and one candidate can be approved as the current favorite.

## Analytics
The system reports review time, average revisions, first-pass approval rate, open comments, and common feedback categories.
