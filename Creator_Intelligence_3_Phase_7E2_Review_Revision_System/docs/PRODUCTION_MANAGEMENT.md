# Production Management

Phase 6E models outsourced editing as a first-class creator workflow.

## Core records

- Editors
- Production projects
- Required assets
- Draft deliveries and versions
- Timestamped review notes
- Revision history
- Production activity history

## Default workflow

Planning → Recorded → Assets ready → Sent to editor → Editing →
Ready for review → Revision requested or Final approved → Thumbnail →
Scheduled → Published

## Creator responsibilities

The dashboard focuses on actions owned by the creator:

- Upload missing assets
- Assign work
- Review delivered drafts
- Resolve timestamped notes
- Request revisions
- Approve final edits
- Prepare thumbnails
- Schedule and publish

## Workload intelligence

Each editor has:

- specialty
- target weekly capacity
- default turnaround time
- current active projects
- drafts waiting for creator review
- overdue projects
- observed average turnaround

The recommendation engine identifies review bottlenecks, overdue drafts,
and editor overload.

## Current limitation

This build stores file locations and cloud URLs but does not yet monitor
Google Drive, Dropbox, OneDrive, Frame.io, or Discord automatically.
